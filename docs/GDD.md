# GDD: 纹章残卷：油画纪年

## 阶段 1 范围

阶段 1 只实现最小可玩战斗循环：

- 20x15 方格地图。
- 玩家单位与敌方单位从 `data/levels/CH01_L01.json` 加载。
- 玩家可选择单位、移动、攻击、等待、结束回合。
- 敌方使用占位行动：接近最近玩家，若在攻击范围内则攻击。
- 胜利条件：击败全部敌军。
- 失败条件：Elara 倒下。

完整四象阵、阵线系统、动态地形、Utility AI、油画 Shader 和 Camp 系统留到后续阶段。

## 游戏支柱

1. 战术站位：后续阶段会通过阵线系统放大站位价值。
2. 地形变化：后续阶段会实现地形记忆和动态地形。
3. 受约束 AI：后续阶段会用 DifficultyProfile 限制 AI 能力。
4. 油画视觉：阶段 1 使用色彩占位，阶段 8 实现完整 Shader 和资产替换。

## 第一关

- ID：`CH01_L01`
- 名称：灰桥伏击
- 目标：击败全部敌军，Elara 存活。
- 教学点：移动、攻击、结束回合、四象克制入口。
- 地图：20x15。
- 玩家单位：Elara、Kael。
- 初始敌军：枪阵军、斥候、魔导士。

## 当前战斗规则

- 移动：曼哈顿距离，暂不计算地形消耗。
- 攻击：若目标在攻击范围内即可攻击。
- 伤害：`max(1, attacker.power + element_bonus - defender.defense)`。
- 四象阵占位加成：优势 +2 伤害，劣势 -1 伤害。
- 单位行动后本回合不能再次行动。
